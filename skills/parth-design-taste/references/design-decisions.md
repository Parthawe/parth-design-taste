# Applying Parth’s taste to a project

Use these decision criteria when the brief leaves room for design direction. Evidence IDs are documented in [evidence](evidence.md). The recommendations translate the research into practice; they are not quotations from Parth.

Pair these criteria with the [annotated visual references](visual-references.md). Open the actual images relevant to the task. Use [foundations](foundations.md) for source-backed portfolio values when exact examples help.

Establish [company context](company-context.md) before choosing a direction. The same principles should produce different choices for different audiences, business models, brands, and surfaces. Adapt execution to the [working model and tools](model-adaptation.md) when capabilities matter.

## What stays consistent and what can vary

| Carry across projects | Choose for each project |
|---|---|
| Clear task and understandable state | Typeface families and exact type scale |
| Coherence across relevant touchpoints | Light, dark, or both themes |
| Behavior that can be assessed | Palette, accent, material, and illustration style |
| Specific recovery and user control | Grid, density, component shapes, and radii |
| Real artifacts and accurate evidence | Framework and component library |
| Deliberate expression with usable controls | Whether 3D, sound, animation, or humor belongs |

## Typography and composition

The portfolio’s Home pairs a high-contrast display serif with plain supporting text. Its project openings use sans titles. Butler’s Slice explores a different serif construction. The transferable choice is the assignment of roles, not one mandatory font pairing. [O1, O5]

For an expressive page, allow a memorable title or composition if the reader can still identify the work and next action. For dense product UI, prioritize scanning, labels, numbers, and state discrimination. Do not place a delicate display face in small controls because the portfolio uses it at large sizes.

Use a readable text measure and allow proof media more width. The local portfolio documentation suggests 65–75 characters for prose and a 1040px case-study frame. Those are portfolio references, not constraints on a dashboard, mobile flow, or another brand. [D1]

## Color and material

Choose a restrained surrounding surface when the project’s own screenshots or objects supply the color. Strong color is appropriate when it belongs to the artifact or brand: TransFi’s blue, the typeface’s purple specimen, Jugalbandi’s stage lighting, and Graveyard’s illustrated landscape all occur in the reviewed site. None establishes a universal favorite color. [O3–O6]

Depth should explain layering, form, construction, or a deliberate scene. A flat list may need no depth at all. A physical installation may need it throughout. Check legibility independently of atmosphere; subtle engraving and dark-on-dark text can become difficult to read.

## Interaction and motion

Choose the smallest representative behavior that answers the design question. For AI input, that may be separate listening, processing, clarification, and recovery states. For a typeface, editable text and weight controls are useful proof. For a physical instrument, an input-to-mechanism-to-output explanation may matter more than a generic feature grid. [O2, O3, O5]

Keep optional explorations subordinate to the main task unless exploration is the purpose. New portfolio-like pages need not inherit the assistant cursor, camera interaction, ambient sound, games, or multiple browsing modes. Where such features are included, make activation intentional and preserve an ordinary way to navigate.

Use project-specific timing. The local reference has 180/360/620ms motion tokens plus a separate duration family; this duplication is a reason to choose and document a coherent scale, not to copy every token. Reduced-motion support is part of the local design intent; the audit did not run a full reduced-motion browser test. [D1, F5]

## Mobile patterns from Mentra and Designwhich

For device control, keep the device name, status, and primary task close together. Size device imagery to help recognition while keeping the action easy to reach. Check text contrast on the actual button fill. Write the heading, description, and recovery action for the current state. An idle disconnect needs different copy from an interrupted call. Reconnecting restores readiness and lets the user choose when to start again.

For an editorial mobile opening, place the headline, short introduction, and work link ahead of large media. A distinct display face can carry the identity while the work supplies the imagery. Give each project a clear action. When a sheet helps a reader preview work in place, check keyboard dismissal and return focus to the project control.

These patterns came from the Mentra call and Designwhich portfolio prototypes. Apply them where the project's audience and task warrant them. Verify the first action, asset loading, layout, and representative recovery paths at the intended mobile sizes. Browser simulation and hardware verification answer different questions.

## Content and evidence

Use a decision sequence when it clarifies the work: question, alternatives, observation or constraint, chosen change, remaining limitation. Avoid forcing every page into that sequence. The live Mentra story’s screen-reading captions are a useful example of giving evidence a specific job. [O2]

Separate original artifacts from later adaptations. Jugalbandi and Enigma distinguish their browser explanations from the original physical systems; Raahi labels demo estimates; TransFi distinguishes a new extension from the original work. Preserve this accuracy when presenting a prototype. Do not infer measured usability from an exhibition, a working animation, or a photograph. [O2–O4]

## Three applications

**New payment product.** Use the product’s brand and transactional density. Put amount, recipient, cost, progress, and recovery where they are needed. An editorial serif and a 3D hero are optional and may be inappropriate. Carry forward clarity and agency.

**Expressive personal portfolio.** Give real work a prominent role, use type with character, and consider one coherent spatial or playful experience. Keep an accessible reading path and direct contact route. Carry forward craft and curiosity without collecting every available effect.

**Small edit within an established brand.** Keep its fonts, colors, tokens, layout, and public interfaces. Improve the requested label, state, or component in that vocabulary. The taste skill should sharpen the decision without expanding the assignment.


## Taste check

Use these checks to judge a substantial new direction against the brief. Each should lead to a concrete decision in the work.

| Check | What to look for |
|---|---|
| First useful action | A wearer can see whether their glasses are ready and start a call. A portfolio visitor can read the introduction and reach selected work before a heavy scene loads. |
| Type roles | Display type carries character where it has room. Supporting text, controls, and small labels use a face and size suited to reading. |
| Artifact and material | The frame gives the actual project room to explain itself. Show the object, interface, or mechanism where it answers a question. Use strong color and texture when the material or brand calls for them. |
| Layout and decoration | Space and alignment make relationships apparent. Gradients, glass, rounded cards, and motion need a specific purpose in the composition. Give a recurring component a consistent radius and hierarchy. |
| Behavior and evidence | Verify the important action and a relevant interruption or failure. Match copy to the actual state. Use real artifacts and label demonstrations and reconstructions accurately. |
